# Надёжность и справка — v89, 29 октября 2026

Основной сайт остаётся на GitHub Pages. DNS, платные планы, облачные базы
и Windows-релизы этим изменением не затрагиваются.

## Что изменено

- Мобильная оптика заранее рассчитывает поле 256×128 и использует его как
  текстуру вместо повторной тригонометрии в каждом пикселе каждого blur tap.
  Один GPU-вызов рисует две боковые полосы, суммарно 30% поверхности.
  Коэффициенты искажения, размытие и форма v88 сохранены. Основные фотографии
  остаются обычными HTML-изображениями в исходном качестве.
- Буфер эффекта ограничен плотностью 1,5; при трёх последовательных дорогих
  отрисовках после прогрева снижается до 1 и 30 кадров/с. Это измерение реальной
  стоимости кадра, без определения тестов/браузера. Нет повторной загрузки
  неизменившегося атласа при уведомлениях resize от панели браузера.
- «Пауза» удерживает движение остановленным после снятия фокуса или закрытия
  превью. При системном reduced motion автоматическое движение отключено,
  кнопка скрыта; ручная клавиатурная навигация сохранена.
- Вход обрабатывает offline до запроса и во время ожидания: код сохраняется,
  сообщение объясняет потерю сети, поздний ответ не открывает магазин.
  После online повторный запрос выполняется вручную.
- `/pomoshch/`, `/pomoshch/rezervnaya-kopiya/`, `/pomoshch/dostup-s-telefona/`
  работают без JS, аналитики и внешних запросов. Названия действий резервирования
  сверены с выпущенным исходным кодом v1.30.0 (`ee421dc`). Восстановление явно
  описано как замена данных, с отдельной копией перед выполнением.
- `tools/pages.json` объединяет список страниц для CSS, CSP, проверки ссылок,
  необязательной preview-сборки и публичной проверки. Sitemap содержит шесть
  канонических страниц. Добавлены TechArticle/BreadcrumbList и ссылки справки.
- `security.txt`, правила сообщения об уязвимостях, еженедельные предложения
  Dependabot и закреплённые SHA официальных Actions. Автослияние не включено.
- После успешной публикации Pages автоматически выполняется read-only проверка
  страниц, CSS/JS, MIME, 404, robots/sitemap/llms и срока security.txt.

## Проверки

Браузерные службы аналитики, подключения и GitHub заменяются заглушками
до открытия страницы. Синтетические продажи, визиты, магазины и сообщения
на настоящих службах не создаются.

Локальный запуск:

```sh
npm ci
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
npm run check:styles
npm run check:csp
npm run check:site
python3 -m venv .venv-browser
.venv-browser/bin/python -m pip install -r tools/requirements-browser.txt
.venv-browser/bin/python -m playwright install --with-deps chromium
.venv-browser/bin/python tools/browser-smoke.py
```

`BROWSER=webkit` выбирает установленный Playwright WebKit. Это автоматизация
браузера, а не испытание на настоящем iPhone. На страницах справки дополнительно
проверяются ширины 320/390/1440 без JavaScript. axe проверяет шесть публичных
страниц при 390/1440, видимую кнопку паузы и диалог входа. Автоматическая
проверка не заменяет тестирование с пользователями.

Исходный замер Lighthouse 13.5.0 опубликованной v88: Performance 65, LCP 2,1 с,
TBT 23 860 мс, CLS 0; Accessibility/Best Practices/SEO по 100. Это лабораторный
мобильный прогон на данной машине с замедлением CPU. Он выявил нагрузку
рендерера, а не полевые Core Web Vitals посетителей. Предварительный локальный
прогон v89 с gzip: Performance 89, TBT 300 мс. Разные сетевые условия не позволяют
выдавать эти две оценки за прямое сравнение.

Повторный замер опубликованной v89 на том же мобильном профиле и машине:
Performance 79, FCP 1,7 с, LCP 2,4 с, TBT 590 мс, CLS 0;
Accessibility/Best Practices/SEO по 100. Условия сети и нагрузки меняются;
лабораторные баллы не гарантируют показатели всех посетителей. Сохраняются
отдельные задачи по полевым метрикам и настоящему iPhone. Публичная проверка
шести страниц, ресурсов, security.txt и настоящей 404 после публикации прошла.
