## Проверено

На локальном HTTP-сервере в Chromium через Playwright:

- Размеры экрана 320×740, 390×844, 768×1024 и 1440×1000: нет горизонтального переполнения, изображения загружаются, якоря действуют.
- Мобильное меню, увеличение обоих экранов, закрытие по Escape, FAQ без JavaScript.
- Форма: чужой домен, отсутствующий магазин, полный адрес своего домена, недоступный сервис, редактирование кода во время запроса. Ответы сервиса и переход на магазин заменены тестовыми данными; реальные магазины не открывались.
- Скачивание: корректный стабильный выпуск и отказ API с сохранением запасной ссылки. Тестовый выпуск — 1.29.3; опубликованный API также проверен отдельно (1.29.4).
- Без JavaScript доступны скачивание, навигация и FAQ; форма предлагает QR-код, неподдерживаемая отправка отключена.
- Страница условий на тех же размерах экрана; ошибок JavaScript нет.
- `node --check app.js`, `git diff --check`, форматирование HTML/CSS/JS.

Ручная визуальная проверка снимков первого экрана и всей страницы на компьютере и телефоне. Проверка мобильной компоновки выполнена в эмуляции Chromium; отдельная проверка на физическом iPhone/Safari не выполнялась. Установщик не запускался, сообщения в WhatsApp не отправлялись.
