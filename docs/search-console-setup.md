# Подключение поиска для metov.store

Техническая подготовка опубликована: публичный HTML, canonical, sitemap,
robots, описание программы, JSON-LD и файл подтверждения IndexNow.
HTML-тег Google получен от владельца и добавлен в `<head>` главной страницы.
После публикации владельцу нужно нажать «Подтвердить» в блоке «Тег HTML»
своего кабинета Google. Успешное подтверждение аккаунта пока не заявляется.
Подтверждение Bing выполняется следующим этапом.

## Google Search Console

1. Открыть [Search Console](https://search.google.com/search-console/welcome)
   в аккаунте владельца. Выбрать «Ресурс с префиксом URL» и ввести точно
   `https://metov.store/`. Этот способ позволяет подтвердить сайт через HTML
   без доступа к настройкам DNS.
2. Выбрать метод «HTML-тег», скопировать полную строку
   `<meta name="google-site-verification" content="…">` и передать её
   разработчику. Это публичный код проверки, не пароль и не API-ключ.
3. Разработчик добавляет полученный тег в `<head>` главной и публикует её.
   После проверки тега на живом домене владелец нажимает «Подтвердить» в Google.
   Тег следует сохранять после подтверждения. Если ресурс уже подтверждён,
   сначала проверить его текущее состояние в аккаунте, а не заменять чужой тег.
4. В разделе Sitemaps отправить `https://metov.store/sitemap.xml`.
   В «Проверке URL» посмотреть главную и страницу о программе, выполнить
   проверку опубликованной версии и запросить индексацию при необходимости.

При варианте «Доменный ресурс» Google выдаёт DNS TXT. Такой токен добавляется
у DNS-провайдера; HTML-тег не подтверждает доменный ресурс. Нельзя генерировать
код самостоятельно или объявлять сайт подтверждённым по наличию sitemap.

## Bing Webmaster Tools

После подтверждения в Google открыть
[Bing Webmaster Tools](https://www.bing.com/webmasters/). Выбрать импорт из
Google Search Console и нужный ресурс metov.store. Проверить, что карта сайта
импортировалась. Если импорт не используется, Bing позволяет подтвердить
ресурс своим HTML-тегом `msvalidate.01` либо файлом `BingSiteAuth.xml`.
Полученный Bing тег также можно передать разработчику для публикации.

IndexNow уже получил три URL с ответом 202: получение подтверждено, проверка
ключа на момент отправки ожидалась. Это не означает подтверждения кабинета
Bing, индексации или присвоения позиции. Файл ключа доступен на домене и
совпадает с конфигурацией проекта; отдельного публичного API статуса проверки
ключа в используемом протоколе нет.

## Обновления после публикации

Workflow `Notify search engines after publication` запускается при изменении
публичных HTML или файлов обхода на `main`. Он проверяет файл подтверждения и
точное содержимое трёх канонических страниц, ожидая публикацию до 240 секунд,
затем один раз уведомляет IndexNow. Повторяется только чтение публикации;
уведомление при ошибке API автоматически не повторяется. Ошибки доступа и
ограничение частоты также не обходятся повторными запросами.

Обновление README или исходников тестов этот workflow не запускает. Он доступен
и вручную из GitHub Actions. Параллельная более новая публикация отменяет
старое ожидание. Если Pages не успевает опубликовать версию, workflow завершается
ошибкой; после устранения причины можно запустить его вручную.

Вручную: `python tools/notify-indexnow.py` показывает URL без сетевых запросов;
`python tools/notify-indexnow.py --submit` проверяет публикацию и отправляет
уведомление. Флаг `--wait-for-publish 240` включает ограниченное ожидание.
Отправлять одинаковые URL по расписанию без изменений не нужно.

## Что измерять

После появления данных смотреть показы, переходы, запросы, выбранный canonical,
ошибки обхода и индексирования. Приоритетные запросы связаны с учётом магазина
инструментов и запчастей, продажами и складом на Windows без интернета, долгами
и арендой инструмента. Позиции по общим словам «программа для магазина» зависят
от конкуренции и региона.

Состояние URL проверяется через URL Inspection, а не только оператором `site:`.
Отсутствие результатов в отдельном публичном поиске не подтверждает
деиндексацию. Для цитирований AI использовать доступные отчёты Bing и реальные
ответы со ссылками; разрешение бота и llms.txt не гарантируют рекомендаций.

Windsor.ai может читать уже подключённые данные Search Console. Его установка
сама по себе не подтверждает сайт в Google и не заменяет действия владельца.
