# AI-функции на первом экране — v91

Сохранены фотографии кассы и телефона, непрерывная лента v90, её 44-секундный
цикл и параметры оптики. Три повторяющихся сцены с техникой заменены
иллюстрациями помощника, распознавания накладной и «Промо». Названия функций
видны на карточках. Responsive sizes соответствуют ширине карточек; добавлен
размер 1024 для телефонов с высоким DPR. Заголовки остаются резкими над зоной
мобильной оптики.

## Основания

AI-помощник, его голосовой ввод, сопоставление накладных и промоматериалы
сверены с компонентами выпущенной v1.30.0, исходный ref ee421dc. В программу
этим изменением не вносились правки. Факт использования в Шымкенте подтверждён
владельцем; полная работа магазина и его оборудования лично не проверена.

Три изображения созданы image_gen по настоящим демонстрационным экранам
программы и прежним студийным сценам. Они являются иллюстрациями, не
фотографиями клиента. Изображения по нажатию подписаны как иллюстрации.
Синий робот и выражения hello/thinking/ok — существующие изображения продукта.

В отдельном блоке показан читаемый схематичный пример на демонстрационных
цифрах: 17 чеков, выручка 396950 ₸, прибыль 142880 ₸ и долг 61300 ₸.
Это не живой чат на лендинге, не реальный результат клиента и не измерение
качества ответа модели. Факты считает программа; AI объясняет и предлагает
переход, проверку и проведение делает человек.

Для AI нужны интернет и собственный ключ Gemini, его квоты/оплата отдельно.
Промоматериалы из каталога работают без AI. Исключительность относительно
всех конкурентов и гарантированные результаты не заявляются.

## Сборка и проверка

Локальные компоненты были захвачены в изолированном стенде без реальных API.
После недоступности среды генерация WebP, CSS/CSP и итоговая проверка выполняются
на бесплатном GitHub Actions для публичного репозитория с contents:read.
Временный вспомогательный workflow удаляется до слияния. Приватный исходный
код приложения в публичный репозиторий не переносится; публикуются только
согласованные изображения персонажа и иллюстрации продукта.

Штатные проверки включают ссылки/метаданные, CSP/CSS, Node/Python, мобильную
вёрстку, непрерывную ленту, альфа-композитинг, fallback GPU и axe.
Внешние службы в браузерных тестах заменяются заглушками. Физический iPhone
этими проверками не заменяется.

Итоговая сборка: 20 Node и 13 Python тестов; Chromium и WebKit; axe без нарушений на восьми публичных страницах при 390/1440; визуальная проверка 320/390/768/1024/1440. Исходные PNG сохранены для просмотра по нажатию, в ленте используются WebP 768/1024/1536.
