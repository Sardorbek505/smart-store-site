# Разные фотосцены и пропорции ленты — 24 октября 2026

## Решение по замечаниям владельца

Прежние фронтальные устройства поверх похожих абстрактных фонов заменены пятью цельными фотографическими сценами, сгенерированными по отдельным промптам:

| Файл                     | Композиция                                                        |
| ------------------------ | ----------------------------------------------------------------- |
| `editorial-laptop.webp`  | Светлый стол, окно и синий блок; ноутбук в ракурсе три четверти   |
| `editorial-monitor.webp` | Монитор под углом на рабочем месте магазина, инструменты и сканер |
| `editorial-phone.webp`   | Телефон по диагонали на синем цилиндре                            |
| `editorial-flatlay.webp` | Рабочий стол сверху: ноутбук, чек, сканер и блокнот               |
| `editorial-scanner.webp` | Предметный крупный план сканера, штрихкода и инструмента          |

Первые четыре сцены генерировались с настоящими скриншотами проекта в качестве референсов. Изображения в фотосценах — результат генерации; точные исходные экраны открываются при нажатии и доступны отдельными переключателями «Касса / Итоги дня». Скриншоты приложения не изменены. В крупном блоке по умолчанию показана фотосцена; в блоке телефона — новая диагональная композиция.

На ширине 1440 px центральная карточка уменьшена с 448 до 330 px, высота ленты — с 355 до 270 px. Карточки шире по пропорциям (1,65:1), боковой разворот усилен. Положение учитывает перспективу, чтобы боковые фотографии не отъезжали слишком далеко от центра и не закрывали соседние кадры. Для мобильных устройств установлены отдельные размеры. Движение, свайпы, пауза и reduced-motion сохранены.

## Референсы

Поиск Pinterest вернул [подборку композиций устройств](https://es.pinterest.com/pin/laptop-and-devices-mockup-composition--808677676847470300/) и [ракурс ноутбука сверху и сбоку](https://in.pinterest.com/pin/macbook-pro-mockup-half-side-view-highangle-shot-apple-comp-computer-device-display-exclusivemockup-halfs--791366965751488960/), но прямое открытие пинов вернуло 403. Дополнительно просмотрено открытое превью [Modern Display / Screen Mockups, Mockup Cloud](https://www.mockupcloud.com/product/modern-display-screen-mockups). Чужие картинки в сайт не встроены: опубликованные фотосцены созданы для проекта.

## Проверка

Chromium / Playwright: 320, 390, 620, 768, 1024 и 1440 px, без переполнения; все изображения загружаются. Визуально просмотрены полная страница и херо на компьютере и телефоне. Проверены движение, пауза/возобновление, наведение, клавиатура, ручные кнопки, свайп без случайного открытия, reduced-motion, остановка вне видимости и сценарий без JavaScript. Увеличение открывает исходный экран, а не сгенерированную фотосцену. JavaScript без ошибок; `node --check app.js`, `git diff --check` и Prettier прошли.

Физические устройства и Safari отдельно не проверены.
