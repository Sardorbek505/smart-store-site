# Визуальная переработка лендинга — 23 октября 2026

Лендинг metov.store находится в `Sardorbek505/smart-store-site`. В основном репозитории приложения `smart-store/landing` сохранён ранний вариант; он не является источником текущего GitHub Pages.

## Изменения

- Первый экран: короткое предложение, крупный заголовок, самостоятельная SVG-иллюстрация кассы и склада в изометрии.
- Фирменный синий, тёплый светлый фон, лаймовые акценты, контрастный раздел с настоящими экранами приложения.
- Продажа, склад и отчётность показаны через графические карточки: чек, объёмные коробки, диаграмму. Числа в иллюстрациях и скриншотах — демонстрационные данные.
- Переключение «Касса / Итоги дня» меняет изображение, подпись и содержимое увеличенного просмотра; состояние кнопок доступно через `aria-pressed`.
- Сокращены описания возможностей, первого запуска и хранения данных. Подробные условия телефона, AI и лицензии доступны в FAQ и на странице условий.
- Сохранены выбор проверенного установщика, обработка кода/адреса магазина, сообщения об ошибках, мобильное меню, увеличение экранов и сценарии без JavaScript.
- Новых зависимостей, внешних шрифтов, аналитики и сервисов нет. `CNAME` и способ публикации не менялись.

## Проверка

Chromium через Playwright, локальный HTTP-сервер:

- 320, 390, 620, 768, 1024 и 1440 px: горизонтального переполнения нет, все изображения загружаются.
- Визуальная проверка полной страницы и первых экранов на 390 и 1440 px.
- Переключение экранов и увеличение актуального изображения, просмотр телефона, закрытие диалога по Escape и кнопке.
- Мобильное меню: открытие, закрытие по ссылке и Escape. Якоря и ссылки на SVG-иконки разрешаются.
- Скачивание: проверенный стабильный выпуск меняет все кнопки; API подменён тестовым ответом. Установщик не запускался.
- Вход: отклонение чужих доменов, вложенных поддоменов, служебных кодов, короткого кода и URL с учётными данными. Проверены отсутствующий магазин, сбой проверки и скрытие старой прямой ссылки при редактировании. Сервис заменён тестовыми ответами; реальные магазины не открывались.
- FAQ работает без JavaScript, кнопка неподдерживаемой отправки формы отключена. Страница условий не переполняется на 320, 390, 768 и 1440 px.
- Ошибок JavaScript нет; `node --check app.js`, `git diff --check`, проверка форматирования Prettier прошли.

Safari и физические телефоны не проверялись. Сообщения в WhatsApp не отправлялись.
