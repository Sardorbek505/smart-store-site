# Компоненты для Smart Store

Просмотрены Bencho (включая указанный Upload dropzone), Morphin, Libraries.dev и 21st.dev. Выбраны компоненты для существующих действий лендинга. Таблица с точными ссылками и происхождением кода находится в [third-party/README.md](../third-party/README.md); MIT-уведомления сохранены рядом.

## Что внедрено

- **Interactive Hover Button / Magic UI, найденный на 21st.** Кнопка «Что внутри»: точка расширяется в фон, вторая подпись с иконкой плавно появляется. Это нативная ссылка; декоративная копия подписи скрыта от скринридера. Срабатывает на hover/focus, никаких таймеров.
- **Скользящий переключатель по демо Bencho и Morphin.** Одна светлая подложка перемещается между тремя вариантами. Равные колонки, процентная геометрия и CSS-transform обходятся без замеров на каждом кадре. Сохраняются подписи, `aria-pressed`, исходные экраны и удобство на 320 px.
- **FAQ по публичному демо Bencho.** Карточки с тонкой рамкой, круглый плюс превращается в крест, ответ ненадолго проявляется. Используются обычные `details/summary`, доступны несколько раскрытых ответов и режим без JavaScript. На коротком экране плотность настроена отдельно.
- **Copy field по публичному демо Bencho.** Кнопка встроена в поле ссылки. Галочка появляется только после успешной записи в буфер. Отказ сбрасывает подтверждение, выделяет адрес и объясняет ручное копирование.
- **Border Beam / Libraries.dev.** Адаптирована маска рамки; цветная текстура делает один проход через CSS-transform при фокусе формы. Нет бесконечного JS-драйвера, размытия или покадровой смены градиента. При reduced motion рамка статична.

Оплачиваемый код Bencho и код Morphin без лицензии не копировались. Для них написаны самостоятельные реализации общих взаимодействий по публичным демо. React, Motion и GSAP в сайт не добавлялись. Новые эффекты не работают непрерывно при прокрутке.

## Проверка

- `tests/components-check.py`: Chromium/WebKit, 390×844 и 1440×900. Быстрое переключение сохраняет правильную подложку; FAQ работает с клавиатуры; копирование проверено с успехом и отказом; рамка завершает движение; reduced motion отключает эффекты.
- `tests/site-review-check.py`: WebKit, 320×568, 390×844, 844×390 и 1440×900. Нет обрезанных переключателей, вопрос по прямой ссылке виден под шапкой, закрытые разделы не создают лишней прокрутки.
- Основная браузерная регрессия, стабильность высоты/прокрутки/поворота WebKit и Axe главной при 390/1440 px прошли. Первый кадр WebKit до и после запуска скриптов совпадает на четырёх размерах: 0 изменений геометрии и пикселей.
- Во время движения рамки Chromium trace: Paint 0, Layout 0, JavaScript FunctionCall 0 и FireAnimationFrame 0; UpdateLayoutTree 1 за интервал замера. Это измерение в среде проверки, а не физический iPhone.
