# Навигация после прокрутки — 24 октября 2026

По просьбе владельца на начальном экране херо скрыты шапка сайта и панель управления каруселью. Шапка фиксированная и не резервирует пустую полосу над херо; скрытое состояние задано в CSS до запуска JavaScript, поэтому при загрузке она не вспыхивает.

После прокрутки более чем на 24 px появляется навигация; при возврате к началу она скрывается, открытое мобильное меню закрывается. Скрытые элементы исключены из фокуса и дерева доступности через `inert` и `aria-hidden`. Обработчик прокрутки пассивный, обновления объединяются через requestAnimationFrame. При reduced-motion переход мгновенный. Глубокие ссылки и восстановленная прокрутка сразу устанавливают правильное состояние.

На странице условий шапка остаётся доступной. Без JavaScript используется статическая навигация.

Проверено в Chromium на 390 и 1440 px: начальное скрытие без зазора, появление после прокрутки, повторное скрытие и закрытие меню наверху, переход сразу к форме магазина, отсутствие вспышки шапки до загрузки JS и статический режим без JS. Браузерная регрессия установки и входа прошла. Синтаксис, Prettier и git diff --check проверены.
