# Сгенерированные 3D-компоненты — v96

По пожеланию владельца объёмные декоративные плашки и значки создаются
инструментом генерации изображений. Код отвечает за размещение, адаптацию,
доступность и движение готовых изображений.

В этой серии сгенерированы четыре самостоятельных компонента с прозрачным
фоном, перламутровой поверхностью, синим корпусом и хромированной кромкой:

- «Голос или текст» — целая плашка с надписью и микрофоном.
- «По данным магазина» — целая плашка с надписью и диаграммой.
- Календарь с часами и стрелкой возврата для аренды инструмента.
- Документ с искрой для накладных с AI.

Материалы и свет согласованы с существующими композициями ноутбука и «14 дней».
Оригиналы: img/accent-{voice,data,rental,invoice}-source-v96.png.
Для плашек используются WebP 480/960, для значков — 96/192. Экспорт только
меняет размер и формат; надписи и иллюстрации созданы генератором, не кодом.

Плашки информационные, не включают микрофон и не отправляют запросов AI.
Их смысл доступен через alt. Значки дополнительных функций декоративные,
текст и ссылки рядом остаются обычной разметкой. Исходные PNG служат запасным
вариантом при ошибке WebP. Изображения загружаются лениво.

Сохраняются конечная анимация появления из v95, уменьшение движения,
запись интерфейса v94 и один просмотр в блоке телефона. Кнопки, поля и
действующие интерфейсы программы остаются рабочими элементами страницы.
