# Переходы в демо и планшетные сцены — v36

После появления демомагазина вход в него оставался только в херо. Карточки
возможностей показывали продажу, склад и отчёт, но не позволяли проверить
соответствующее действие. Теперь каждая карточка — большая область обычной
ссылки с видимой подписью «В демо» и стрелкой:

| Карточка | Адрес           | Экран                                    |
| -------- | --------------- | ---------------------------------------- |
| Продажи  | `demo/#sale`    | Поиск товаров и учебный чек              |
| Склад    | `demo/#stock`   | Заполненный каталог с ценами и остатками |
| Контроль | `demo/#reports` | Выручка, прибыль, оплаты и история       |

Ссылка «Демо» добавлена в существующее меню. В херо навигация скрыта, как
и прежде. Карточки сохраняют прежние размеры и изображения; явная подпись
делает действие понятным на сенсорном экране. Ссылка покрывает всю карточку,
имеет доступное имя и контрастный контур при фокусе с клавиатуры.

Существующий CSS для ширины 851–1100 px вынимал изображения двух правых
карточек из потока, смещал их за границы и задавал opacity 0.28. Правило
удалено: текст и изображение теперь занимают свои колонки, сцены полностью
видны и непрозрачны. Номера и названия карточек остаются на одной строке.

При высоте до 600 px прежние правила также сжимали три карточки в ряд
и оставляли иллюстрациям крошечную колонку. На экранах шириной до 1100 px
в этом режиме используется существующее перелистывание одной крупной карточки;
CSS и проверка media query в `scripts/interface.js` согласованы. Выше 1100 px
сохраняется композиция из трёх карточек с компактной типографикой.

В поле ссылки для продолжения установки прежние адаптивные правила
перезаписывали исходный размер шрифта 16 px значениями 12–15 px. Эти
переопределения удалены, включая альбомную ориентацию: поле остаётся 16 px.
Это убирает известное условие автоматического приближения полей в iOS Safari;
проверено вычисленное значение, физический iPhone недоступен.

Новых JS-модулей, изображений, библиотек или фоновой загрузки демо не добавлено.
Используются готовые страницы и их существующие маршруты. Версия загрузчика
повышена до `app.js?v=36`, чтобы обновить media query существующего интерфейса.
Обновлённый CSS имеет новое имя с хешем; предыдущий опубликованный файл
сохранён для HTML из кэша.

## Проверка

`tests/landing-demo-check.py` в WebKit и Chromium покрывает 320×568, 390×844,
768×1024, 844×390, 932×430, 851×768, 1024×600, 1024×768, 1440×500 и 1440×900:

- три карточки → нужный маршрут демо → возврат браузером;
- активация Enter на телефоне, переход через меню, обычные ссылки без JS;
- перелистывание кнопками и клавиатурой в каждом компактном режиме;
- размеры области нажатия, текст внутри карточек, расположение навигации;
- шрифт поля ссылки, отсутствие горизонтального переполнения и ошибок JS.

`tests/image-fit-check.py` дополнен планшетными и широкими невысокими размерами
и проверкой непрозрачности сцен. Проверяется фактически отрисованная область предметов,
включая все сцены херо, телефона и остальных блоков.

Также проверены первый кадр, загрузка лендинга, путь установки/копирования,
просмотр экранов и существующие расчёты демо. Артефакты браузерной проверки
создаются в `/tmp/smart-store-landing-v36/{webkit,chromium}`.
