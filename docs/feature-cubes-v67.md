# Возможности: парные кубы, v67

Блок «Продажи. Склад. Контроль.» использует две плоскости с настоящими соседними
гранями CSS 3D: текст и визуальный пример поворачиваются в противоположные
стороны по оси X. Сохранены исходные три статьи, фотографии, конечные примеры,
подписи и ссылки на оригинальные экраны. На телефоне пример крупно стоит над
текстом; высота раздела и число разделов сохраняются.

Первый поворот происходит один раз при появлении и остановке прокрутки.
Остальные переходы запускаются кнопками, стрелками/Home/End и горизонтальными
свайпами. Вертикальный жест остаётся прокруткой страницы. Быстрые нажатия
обрабатываются последовательно; переходы используют только transform через
WAAPI и освобождают анимации после завершения. Во время диалога, скрытия вкладки
и ухода из видимости переход останавливается. Невидимые микро-примеры не
запускаются; выбранный пример начинает собственную анимацию после поворота.

При уменьшенном движении переход статический. Клавиатурный фокус завершает
вступительный поворот; доступна только выбранная грань. Восстановление истории
просмотра оригинального экрана также восстанавливает соответствующую возможность,
включая перезагрузку и Forward после переключения на другую функцию.
Для старого закэшированного CSS проверяется маркер версии до изменения DOM.
Без JS или при отказе enhancement остаются исходные карточки; вход и установка
загружаются независимо. Новые внешние сервисы и зависимости не добавлялись.

Проверки: `tests/feature-cubes-check.py` — десять размеров в Chromium и WebKit,
включая движение панели браузера на коротком телефоне, историю предпросмотра,
reduced motion, очередь переходов, фокус и fallback. Указанные сценарии
синтетических PointerEvent проверяют направление свайпа; Chromium дополнительно
получает настоящую последовательность touch через CDP. Также проверены
существующие микро-анимации на 12 размерах и уточнённые компактные состояния,
полные виджеты/фотографии и повтор, вход, установка, просмотр, меню и копирование
ссылки. WebKit — проверка движка, а не испытание физического iPhone.

На момент подготовки исходников основной домен обслуживает v66. Публикация v67
выполняется отдельно через существующую авторизацию владельца и обновляет
только пакет лендинга. Отдельная видеозапись показывает локальную проверенную
сборку; production-события при записи не
создавались.
