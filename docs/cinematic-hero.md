# Херо по визуальному референсу — 23 октября 2026

## Что изменилось

Первый экран metov.store теперь строится вокруг центрального заголовка и движущейся ленты мокапов на тёмном фоне. Карточки проходят по дуге: центральная плоская, боковые разворачиваются в перспективе и выходят за края экрана.

Для проекта сгенерированы три сцены: кобальтовая стеклянная волна, янтарное световое кольцо и лаймовое стекло с подиумом. Публикуются оптимизированные WebP-файлы `img/studio-{blue,amber,lime}.webp` — суммарно около 283 КиБ. Сцены также используются в крупных мокапах компьютера и телефона ниже по странице.

Устройства собраны отдельным слоем поверх сцен. Внутри — существующие настоящие скриншоты `sale.png`, `home.png` и `phone.png` с демонстрационными данными: изображение интерфейса не перерисовывается генератором. Нажатие открывает оригинал экрана в увеличенном просмотре. Новых зависимостей и внешних запросов не добавлено.

## Поведение ленты

- Автоматическое непрерывное движение, кнопки назад/вперёд, стрелки клавиатуры и горизонтальный свайп.
- Пауза по кнопке, при наведении, фокусе клавиатуры, открытом просмотре, скрытой вкладке и уходе ленты за пределы экрана.
- При `prefers-reduced-motion: reduce` автодвижение отключено, ручное переключение мгновенное. Изменение настройки обрабатывается без перезагрузки.
- Кнопки снабжены названиями, ручное переключение объявляет выбранный экран. Далёкие карточки исключаются из фокуса через `inert`.
- Без JavaScript остаются статические мокапы, прямые ссылки на скриншоты, скачивание и навигация; неработающие элементы управления скрыты.

## Проверка

Chromium / Playwright на локальном сервере:

- 320, 390, 620, 768, 1024 и 1440 px: нет горизонтального переполнения; все 14 изображений загружаются. Визуально просмотрены первый экран и вся страница на телефоне и компьютере.
- Автодвижение, пауза и возобновление, остановка при наведении и выходе из видимости, ручные кнопки, клавиатура, динамическое изменение reduced-motion.
- Свайп переключает карточку и не открывает просмотр; отдельное касание открывает оригинальный скриншот.
- Увеличение правильного скриншота из ленты; переключение и увеличение экрана из крупного мокапа; закрытие по Escape.
- Мобильная компоновка и статическая навигация без JavaScript.
- `node --check app.js`, `git diff --check`, Prettier. Ошибок JavaScript не обнаружено.

Проверка свайпа — эмуляция Chromium; физические устройства и Safari отдельно не проверялись. Работа кассового приложения и установщик не менялись.
