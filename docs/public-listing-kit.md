# Материалы для внешних карточек Smart Store

Тексты подготовлены для публикации владельцем в доступных ему каталогах и
профилях. Заявки и сообщения третьим лицам не отправлялись.

## Короткое описание

Smart Store — касса и склад для магазинов инструмента и запчастей на Windows.
Продажи, закупки, остатки, долги покупателей и аренда инструмента. Основной
учёт работает без интернета. Русский и казахский интерфейс, 14 дней на пробу.

## Полное описание

Smart Store помогает вести магазин инструмента и запчастей на компьютере
с Windows 10/11, 64 бита. Продавец находит товар по названию или штрихкоду,
формирует чек и указывает наличные, Kaspi или долг. В программе есть закупки,
остатки, история продаж, долги и аренда инструмента.

Основные операции доступны без интернета. Для доступа с телефона компьютер
должен быть включён, а для подключения извне нужен интернет. Распознавание
накладных использует собственный ключ Gemini и квоты Google; результат проверяет
пользователь. Лицензия оплачивается один раз на один компьютер, стоимость
сообщается в WhatsApp. Первые 14 дней можно работать без кода активации.

## Подтверждённое внедрение

Smart Store установлен в магазине «Электроинструменты» в Шымкенте.
Это подтверждено владельцем проекта и разрешено к публикации. Срок работы,
имя сотрудника, отзыв, фотографии магазина и измеренный результат не получены.
Их нельзя добавлять по предположению. Скриншоты сайта показывают учебные данные,
их подпись: «Пример интерфейса Smart Store с демонстрационными товарами».

Для полноценного кейса нужны факты: какие задачи магазин выполняет в программе,
период использования и подтверждённый результат; для фото и цитаты — разрешение
их владельца. До получения этих материалов используется только установленный факт.

## Темы полезных материалов

Первый приход и продажа; учёт инструмента по штрихкоду; покупка в долг;
аренда инструмента; работа без интернета; резервная копия и восстановление.
