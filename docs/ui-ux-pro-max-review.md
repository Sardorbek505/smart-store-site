## Найдено и исправлено

| Проблема                                                                                                  | Исправление                                                                                      |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| У мобильной ссылки «Вход» отсутствовало доступное имя: длинная подпись скрыта CSS, короткая — aria-hidden | Явное `aria-label="Войти в свой магазин"`                                                        |
| Подписи, условия пробы, данные выпуска и часть основного текста имели размер 7–11 px                      | Минимум 12 px для подписей, 16 px для основных описаний; больше размер ссылок и кнопок           |
| Поле магазина на телефоне имело шрифт 12 px                                                               | 16 px для полей ввода, включая ссылку установки, чтобы избежать автоматического увеличения в iOS |
| Управление каруселью и меню имело компактные области нажатия                                              | Области 44×44 CSS px для удобства; это выбранный запас, а не заявление о минимуме WCAG для веба  |
| После увеличения текста пара CTA могла не помещаться в одну строку                                        | Перенос действий; на телефоне информационные пункты о данных располагаются в один столбец        |
| Синяя ссылка входа с телефона на тёмном фоне имела слабый контраст                                        | Светлый синий для ссылки; светлый индикатор фокуса в тёмных разделах и шапке                     |

## Проверено

- axe-core 4.14.0: категории WCAG 2 A/AA, 2.1 AA и 2.2 AA. До правок найдено серьёзное нарушение `link-name` на мобильной версии. После правок — 0 обнаруженных нарушений на главной при 390 и 1440 px и на главной/условиях в дополнительных проверках 375, 640 и 844 px.
- Проверка текста: среди видимых параграфов, подписей полей, полей, summary и кнопок нет шрифта меньше 12 px.
- 320–1440 px: изображения загружаются, горизонтального переполнения нет. Дополнительно 375×812 и 844×390; ширина 640 CSS px проверена как сценарий reflow при увеличении масштаба настольного окна. Это проверка компоновки, не утверждение о тесте физического устройства или системного увеличения шрифта.
- Клавиатурный фокус останавливает карусель; reduced-motion отключает автодвижение. Меню, альтернативы свайпу и просмотр экранов работают.
- `tests/browser-check.py`: установка Windows, передача ссылки с телефона, форма магазина, ошибки сервисов, отмена запроса, изоляция отказа галереи, просмотр и режим без JavaScript прошли.
- Синтаксис и форматирование изменённых файлов проверены. Автоматический аудит дополняет ручной просмотр; полной сертификацией доступности не является. Safari и физические устройства отдельно не проверялись.
