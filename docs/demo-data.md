# Полный демомагазин и новые мокапы — v28

Просмотр: https://metov.store/?v=28 и https://metov.store/?v=28#workspace.

Проблема: на прежней кассе только один товар имел фотографию, а главная показывала почти пустой график. Теперь демонстрационные экраны получены из реальных React-компонентов приложения с одним набором мок-данных. Телефон использует настоящий `src/main/mobile/page.ts`. Интерфейс не нарисован генератором или отдельной HTML-копией приложения.

## Данные

`tools/demo/fixture.mjs` содержит каталог и 173 завершённые продажи за 14 дней. Деньги — в тиынах, количества — в тысячных, как в приложении. Выручка, прибыль, средний чек, категории и оплаты вычисляются из одних строк продаж; показатели компьютера и телефона совпадают.

| Показатель за 24.10.2026 |  Значение |
| ------------------------ | --------: |
| Выручка                  | 396 950 ₸ |
| Прибыль                  | 142 880 ₸ |
| Чеков                    |        17 |
| Средний чек              |  23 350 ₸ |
| Наличные                 | 194 300 ₸ |
| Kaspi                    | 141 350 ₸ |
| Отгружено в долг         |  61 300 ₸ |
| Получено деньгами        | 335 650 ₸ |

Наличные + Kaspi + долг = выручка; долг не включён в сумму полученных денег. На главной видны сравнение со вчерашним днём, все 14 пар столбцов и три категории за неделю. Курс, резервная копия, остатки и задолженности также имеют демонстрационные значения.

- Каталог: 10 товаров с артикулами, категориями, брендами, ценой, себестоимостью, оптовой ценой и остатками. У шуруповёрта 12 шт, дисков 240 шт, бура 38 шт; у перфоратора отмечен малый остаток 3 шт.
- Касса: у всех четырёх видимых карточек есть сгенерированные предметные фотографии — шуруповёрт, диск, бур и молоток. Черновик: 2 шуруповёрта, диск и бур; 3 позиции, 4 единицы, всего 82 300 ₸.
- Оплата: настоящий диалог приложения, смешанная оплата 40 000 ₸ наличными + 42 300 ₸ Kaspi. Кнопка проведения доступна; операция не отправлялась в рабочую базу.
- Телефон: те же показатели дня и заполненный график; поиск «Набор» показывает два существующих товара из каталога — 7 и 14 шт. В корзине отдельный пример: шуруповёрт + диск, 40 550 ₸. Этот пример совпадает с чеком на иллюстрации продажи.

Демонстрационная дата фиксирована, часовой пояс — Asia/Almaty. Используются исключительно локальные фиктивные IPC/API-ответы; реальная база магазина и репозиторий приложения не менялись. Источник компонентов: `Sardorbek505/smart-store`, commit `6aa6219ea05addd40e1aada99a4a531518728925`.

## Экраны и изображения

В лендинге используются новые PNG: `demo-sale`, `demo-home`, `demo-products`, `demo-payment`, `demo-phone`, `demo-phone-search`, `demo-phone-cart`. Компьютер — 1440×900; телефон — 390×844, DPR 2. Все ссылки просмотра оригиналов, сцены, шаги, подсказки и числовые выноски обновлены вместе.

Заново сгенерированы все 10 мокапов, содержащих экран: четыре сцены херо, три сцены программы, три iPhone. Первым референсом генератору передавался новый реальный PNG; вторым — прежняя полная композиция устройства. Промпт требовал заменить старый экран целиком, сохранить фотографии всех четырёх товаров, заполненные графики и точные новые суммы, оставить корпус и аксессуары внутри кадра, фон — прозрачным. Ракурсы и материалы сохранены. Фото сканера и три иллюстрации без экрана не требовали подмены UI.

Сопоставление десяти оригиналов генератора и сцен сохранено в `tools/demo/generated-assets.json`. Оригинальные PNG находятся в `/workspace/generated_images`; WebP и responsive-размеры херо получены только кодированием/масштабированием. Программного монтажа UI на корпус нет.

Четыре фотографии товаров также созданы генератором, затем переданы в штатный `window.api.photos.get`. Промпты: square isolated catalogue photograph; complete single product, warm-white studio background, no logo or text, full edges; blue/black cordless drill, black cutting disc with blue centre, silver SDS bit, steel hammer with blue/black handle. Оригиналы:

- `exec-cd70846e-c6d6-4f00-8279-a18e264227eb.png` — шуруповёрт;
- `exec-40cb7d52-5e35-4892-aeae-9c6eb722471e.png` — диск;
- `exec-600e7929-a5ef-4939-8ee6-deab8e6b9131.png` — бур;
- `exec-20a980e7-b4fa-4127-a11b-884931dd5954.png` — молоток.

Новые имена файлов и `?v=28` исключают повторное использование старых изображений из кеша. Демо-обвязка и её зависимости нужны только для получения скриншотов; в браузер лендинга они не загружаются.

## Воспроизведение

Обвязка сборки, fixture и захват находятся в `tools/demo`; зависимости устанавливаются отдельно от лендинга. Пример:

```sh
npm install --prefix /tmp/smart-store-demo-deps esbuild@0.28.2 react@18.3.1 react-dom@18.3.1 recharts@3.10.1 uuidv7 zod@4.6.7 tailwindcss@4.3.3 @tailwindcss/cli@4.3.3
node tools/demo/build.cjs /path/to/smart-store /tmp/smart-store-demo-deps/node_modules /tmp/smart-store-demo-render
/tmp/smart-store-demo-deps/node_modules/.bin/tailwindcss -i /tmp/smart-store-demo-render/input.css -o /tmp/smart-store-demo-render/out.css --minify
python -m http.server 4174 --directory /tmp/smart-store-demo-render
```

В другом терминале с Python Playwright и Chromium:

```sh
DEMO_RENDER_DIR=/tmp/smart-store-demo-render python tools/demo/capture.py
```

Захват проверяет загрузку четырёх фото, 28 столбцов графика, показатели, доступность кнопки смешанной оплаты и отсутствие ошибок JavaScript. Существующие story/image-fit/browser/first-paint проверки проверяют интеграцию с лендингом, оригиналы, все состояния, границы изображений и мобильную геометрию.
