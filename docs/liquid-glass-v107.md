# Навигация с оптикой Glisse — v107

Источник: [Glisse](https://github.com/0kzh/glisse), версия 0.6.0,
commit `4922c852a6866ee9991d2f8c715bb1cfbe7aa2b9` (MIT, Kelvin Zhang).
`tools/glisse/lens.ts` и `svg.ts` взяты из `src/internal/`; `rim.ts` содержит
чистую функцию `rimMap` из `refraction.ts`. Лицензия сохранена в
`third-party/Glisse.LICENSE`. `navigation.ts` — адаптер к текущему HTML сайта.
React и остальные компоненты библиотеки не подключаются.

Панель использует тонкий направленный блик Glisse, размытие 3 px,
цветовое разделение 0.6 и краевую линзу с параметрами `GLASS` из библиотеки.
Тёмная заливка усилена с 62% до 68%, чтобы светлые подписи оставались
читаемыми и поверх белой фотографии. Светлая заливка — белая с 60%.
Яркая сплошная обводка и многослойные внутренние тени удалены.

Chromium применяет SVG-линзу к живому фону. Safari и Firefox используют
нативное размытие, прозрачность и тот же растровый блик: произвольный живой
фон через SVG backdrop-filter эти движки не преломляют. На физическом
Safari/iPhone результат в этой среде не проверен; тест ветки без преломления
проверяет выбор fallback, а не заменяет проверку WebKit.

Бандл 13.2 КБ загружается только после первого появления навигации.
Нет requestAnimationFrame-цикла и обработки каждого scroll-события.
Линза пересчитывается при изменении размера; старый SVG-фильтр удаляется.
Блик пересчитывается также при смене тона секции. Режим уменьшения
прозрачности отключает оптику и оставляет непрозрачную панель.
Отказ дополнительного бандла сохраняет CSS-панель, меню и вход.

Проверки: `npm test`, `check:site`, `check:styles`, `check:csp`, `check:glass`;
`tests/glisse-navigation-check.py` проверяет реальные изменения пикселей
на краю и отсутствие изменений в центре, отсутствие накопления фильтров,
уменьшение прозрачности и отказ бандла на 320/390/768/1440 px.
`tests/navigation-glass-check.py` проверяет передачу цвета, размытие,
контраст не ниже 4.5:1 и выбор тона секции. Финальный короткий FAQ может
не доехать до панели при достижении конца страницы; тест учитывает секцию,
которая фактически находится под панелью.
