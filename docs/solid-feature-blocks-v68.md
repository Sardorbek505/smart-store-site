# Объёмные блоки возможностей, v68

«Продажи. Склад. Контроль.» использует два соприкасающихся куба. Каждый замкнут
шестью гранями: четыре грани по кольцу X и две боковые заглушки. Общая камера
слегка наклонена; соседние грани видны и в покое. При переходе WAAPI вращает
только два родительских тела в противоположных направлениях. Все грани постоянно
прикреплены к телам, поэтому между ними не открывается пустота.

Кубы остаются рядом на телефоне. Слева — крупный номер и название функции,
справа — исходный пример поверх фотографии. На маленькой грани виден итог:
сумма чека, остаток товара или выручка с графиком. Полное описание и действия
расположены под объектом, а исходные экраны открываются прежними ссылками.
Повтор каждого примера работает и после переноса подписи; демонстрационные
суммы и подписи не изменены. Количество разделов, вход и установка сохранены.

Первый поворот ждёт появления блока и остановки прокрутки. После поворота
запускается только выбранный пример (3 секунды). Автоматическая смена ждёт
4,2 секунды, затем выполняет поворот 1,15 секунды с небольшим запаздыванием
правого куба. Переход от третьего примера к первому проходит через синюю грань
и длится 1,6 секунды. Есть явная пауза/продолжение. Ручное переключение, повтор
примера или взаимодействие с подписью отключает автоматическую смену.

Скрытая вкладка, прокрутка, удерживаемый touch, уход из видимости и открытый
диалог приостанавливают движение. После возвращения не накапливаются пропущенные
переходы. Клавиатура, циклические стрелки и горизонтальный свайп доступны;
вертикальный жест остаётся прокруткой. Автоматические смены не объявляются
aria-live. Невидимые описания и статьи исключены из фокуса. История просмотра
восстанавливает функцию и ссылку, в том числе после Reload и Forward.

Reduced motion оставляет статические состояния. Отсутствие JS, недоступные
API или старый CSS оставляют исходные карточки. Для CSS сохраняются две прежние
сборки, поскольку Pages и production Worker могут обслуживать разные версии.
Новые зависимости, серверные обработчики и внешние сервисы не добавлены.

Проверки и видеозапись выполняются локально с перехватом сетевых счётчиков.
Публикация на metov.store выполняется отдельно через уже существующую
авторизацию Wrangler владельца. Проверка WebKit не заменяет испытание на
физическом iPhone.
