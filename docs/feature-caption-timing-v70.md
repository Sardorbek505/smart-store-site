# Согласованное описание поворота, v70

При переключении подпись и счётчик раньше сразу менялись на следующий пример,
пока оба куба ещё показывали предыдущую грань. Теперь целевое состояние движения
и последнее показанное состояние учитываются отдельно. Подпись, счётчик и
доступная статья обновляются вместе после завершения обоих поворотов, включая
небольшую задержку правого куба. Собственная микро-анимация по-прежнему начинается
только после остановки.

Кнопки исходного экрана и повтора временно исключены из взаимодействия при
повороте: нельзя открыть предыдущий экран по подписи, пока грань уже меняется.
Контейнер отмечен aria-busy. Фокус на самом контейнере больше не обрывает текущий
поворот. Восстановление истории согласует подпись и тело, даже когда сохранённый
экран относится к входящей, ещё не остановившейся грани.

Сохранены понятный пример 40 550 ₸ → остаток 12 → 11 → прибавка к выручке,
крупные надписи, закрытые объёмные тела, пауза 6 секунд и существующее управление.
Число разделов и геометрия объектов не менялись. Новый CSS сохраняется рядом с
v69 и фактически используемым на основном домене v66 для кэшированных страниц.
Переключение основного домена на GitHub Pages отложено владельцем до возвращения
домой; это изменение его не выполняет и не возвращает production Worker config.

Проверки: 10 размеров в Chromium и WebKit, reduced motion, обычное движение,
пауза за диалогом и вне экрана, очередь нажатий, ожидание подписи и счётчика,
восстановление Forward во время поворота, кэшированный CSS и отсутствие JS.
Все 20 Node-тестов, CSP/стили/ссылки и preview dry-run прошли. Отдельная
мобильная видеозапись показывает полный цикл трёх состояний. Публичный preview
v70 проверен в мобильном браузере: подпись ждёт окончания поворота, исходный
экран открывается правильно, ошибок JS нет. Внешние события заменены fixtures.
