результаты AI. Нет запроса Gemini, настоящего файла поставщика, производственной
базы или данных клиента. Скорость записи не является замером работы AI.

плеер и подписи также раскрывают это.

## Остальная готовность на 29 октября

Все восемь канонических публичных страниц отвечают HTTP 200 и не возвращают
X-Robots-Tag: noindex. Локальная проверка подтверждает canonical, sitemap,
robots и доступность для перечисленных поисковых ботов. Публичный поиск по
site:metov.store и двум дополнительным запросам не показал результатов в
доступном поисковом инструменте. Это не доказательство отсутствия индексации;
статистика Google Search Console и Яндекс Вебмастера в этой среде недоступна.
Новые URL не создаются; штатное уведомление IndexNow запускается после
совпадения опубликованного HTML.

Последний публичный установщик — v1.30.0, 167916373 байта. Проверка диапазона
0–1 вернула HTTP 206, Content-Range bytes 0-1/167916373 и сигнатуру MZ.
Это подтверждает доступность файла Windows, но не установку, SmartScreen,
первый запуск на физическом ПК или работу сканера/принтера. Такие проверки
в Linux не выдаются за пройденные; Windows Sandbox и сборка релиза не запускаются.

Кейс в Шымкенте дополнен реальными экранами приложения на демоданных.
Скриншотов базы клиента и измеренных результатов магазина не предоставлено;
они не выдумываются. Подтверждённые владельцем функции уже описаны в кейсе.

Браузерная проверка публичного сайта с User-Agent Windows подтвердила, что
кнопки скачивания получают URL текущего публичного установщика из настоящих
метаданных GitHub Release. На телефоне кнопка открывает инструкцию переноса
ссылки на ПК. Сам установщик при этих проверках не запускается. Службы
аналитики и поиска магазина заменены заглушками; тестовых событий на
производственные счётчики не отправлено.
