# Качество интерактивной кассы, v56

У прежней сцены на обычном дисплее DPR=1 было по одному пикселю рендера
на CSS-пиксель. На скруглениях появлялись ступеньки; мелкий интерфейс
шумел при уменьшении. Металлические детали без окружения выглядели серыми.

Теперь framebuffer использует 2× по каждой стороне, включая обычные дисплеи,
с ограничением 2,1 млн пикселей на большой сцене. На телефоне с DPR=3
остаётся прежний предел 2×. Аппаратное MSAA сохранено. Это повышает стоимость
отрисовки на обычном компьютере; измерения ниже относятся к браузерному стенду,
а не к физическому iPhone.

Вместо снимков 1440×900 подготовлены lossless WebP 2880×1800 через изолированный
стенд настоящего приложения с мок-данными. `tools/demo/capture-checkout-textures.py` повторяет экспорт через тот же стенд.
CSS-размер остался 1440×900 при DPR=2:
компоновка интерфейса не изменилась. Продажа содержит два шуруповёрта,
диск и бур на 82 300 ₸. Оплата: 40 000 наличными и 42 300 Kaspi.
Суммарный вес двух текстур — 669 694 байта. Используются mipmaps и анизотропия
до 8× для уменьшения шума на наклонном экране. В общем виде мелкие надписи
ограничены физическим размером монитора; три приближения показывают детали.

Грани корпуса и стойки сглажены с сохранением плоских поверхностей.
Отражения RoomEnvironment выпекаются через PMREM один раз в кубическую карту
128 px. Контактные тени под оборудованием нарисованы в одной текстуре;
она добавляет один проход геометрии. Живых отражений и shadow maps нет.
В общем виде: 16 614 треугольников, 20 вызовов отрисовки; в приближении
видимая часть сцены — 3 134 треугольника, 6 вызовов. Ресурсы освобождаются
при dispose, включая окружение и текстуру контактной тени.

Позиции камеры, области приближения, расположение кнопок и точки выносок
сохранены. Постеры `checkout-{overview,0,1,2}-v56.webp` заново сняты из реального
движка в 1600×1200 с WebP quality=96. Старые v46 оставлены для кэшированного
HTML. Новый bundle также сохраняет предыдущий опубликованный файл.

Проверки:

- `npm test`, `npm run check:styles`, `npm run check:checkout`, проверка hero.
- `tests/checkout-quality-check.py`: реальный framebuffer на DPR=1 и DPR=3,
  ограничение пикселей, MSAA, текстуры 2880×1800 и три приближения.
- `tests/checkout-3d-check.py`: пять размеров, целые области экрана,
  клавиатура, паузы, отсутствие GPU, ошибка текстур, потеря и возврат контекста.
- `tests/checkout-ambient-check.py`: девять фаз движения без обрезки,
  не более 30 кадров/с, ноль GL-вызовов при прокрутке/паузе, неподвижные кнопки.
- `tests/image-fit-check.py`: целые предметы на резервных изображениях
  и остальных иллюстрациях лендинга.

Браузерные проверки выполняются в Chromium и WebKit. Автотесты не заменяют
проверку плавности на физическом iPhone / Safari.
