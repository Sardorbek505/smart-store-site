# Возврат лендинга на GitHub Pages

Состояние на 28 октября 2026 года: исходники и GitHub Pages готовы, переключение
основного домена ещё требует изменения проксирования DNS в аккаунте владельца.
В окружении помощника нет авторизации этого аккаунта Cloudflare. Изменение
файлов репозитория само по себе не отключает уже опубликованный маршрут Worker.

## Что проверено и подготовлено

- GitHub Pages API сообщает `built`, source `main` / `/`, CNAME `metov.store`,
  `https_enforced: true`. Сертификат для metov.store и www.metov.store одобрен,
  срок действия — до 15 января 2027 года.
- При подготовке возврата публикация Pages для исходников v69 (`d6567cd…`) прошла:
  workflow `40688381004`, артефакт `github-pages` `12815543522`.
- Публичный metov.store по-прежнему возвращает v66 и прежний CSS. Поэтому возврат
  ещё не объявляется завершённым.
- Приём аналитики и диагностики остаётся на `https://zavod.metov.store/hit`
  и `/act`. Реальные OPTIONS-запросы с Origin `https://metov.store` вернули 204,
  разрешены POST и OPTIONS. Синтетические визиты и события не отправлялись.
- Удалена `edge/wrangler.jsonc`, которая повторно прикрепляла лендинг к маршрутам
  основного домена. CI проверяет только необязательный preview-конфиг.
  Клиентский код статистики, сервер подключения и «Завод» не менялись.

## Переключение с телефона

Cloudflare → metov.store → DNS → Records. Только для записей корня домена и www
переключить Proxy status с Proxied на **DNS only** (серое облако).
Если значения DNS отличаются от таблицы, вернуть указанные значения GitHub Pages:

| Имя | Тип | Значение | Proxy status |
| --- | --- | --- | --- |
| @ / metov.store | A | 185.199.108.153 | DNS only |
| @ / metov.store | A | 185.199.109.153 | DNS only |
| @ / metov.store | A | 185.199.110.153 | DNS only |
| @ / metov.store | A | 185.199.111.153 | DNS only |
| www | CNAME | sardorbek505.github.io | DNS only |

Действующие записи почты, `zavod`, `connect`, туннелей магазинов и остальных
поддоменов сохраняются. Не использовать общую паузу Cloudflare для всей зоны:
она затронет другие проекты. Сам Worker можно пока оставить как архивную копию;
при DNS only его старые маршруты не обслуживают трафик корня и www.

## Проверка завершения

После переключения и обновления DNS проверить metov.store и www по HTTPS,
совпадение загрузчика и CSS с текущим `index.html` ветки `main`,
все три публичные страницы,
верификации поисковиков, настоящий 404, вход и исходные экраны. Метрики
остаются внешними POST в «Завод»; для браузерных проверок использовать fixtures.
Проверка публикации не должна создавать визиты или опрашивать реальные магазины.

Обычные дальнейшие правки: PR → успешная проверка → main → автоматическая
публикация Pages. Старые Windows-скрипты публикации Worker для лендинга
больше не запускать. После подтверждения основного домена можно повторить
ранее остановившееся уведомление IndexNow; новое уведомление до переключения
не запускать.
