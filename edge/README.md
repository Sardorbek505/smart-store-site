# Подготовленная публикация с HTTP-заголовками

Сейчас metov.store обслуживается GitHub Pages. Эта папка готовит отдельный
Cloudflare Worker со статическими ресурсами. Она не меняет текущий домен
и не является конфигурацией GitHub Pages. Preview опубликован 28 октября 2026:
[проверки и оставшиеся действия](../docs/deployment-2026-10-28.md).
Production-маршруты основного домена пока не подключены.

В ответах есть `nosniff`, `DENY`, ограничение разрешений и HSTS на 180 дней без
`includeSubDomains`/preload. Отдельный CSP запрещает встраивание; точные script-хеши
в HTML продолжают действовать. Настоящие 301 нормализуют www, `/index.html`,
старый `/demo/` и адрес инструкции за один переход. `.html` страницы условий
и настоящий статус 404 сохраняются. Preview получает `X-Robots-Tag: noindex`.

Пакет содержит 151 разрешённый публичный файл: страницы, JS, изображения,
собранные ресурсы, лицензии и файлы подтверждения поиска. `.git`, `.env`,
инструменты, отчёты и тесты в пакет не входят. Сборщик проверяет предел 25 MiB
на файл и отказывается от символических ссылок/source maps.

## Проверка

Из корня репозитория:

```sh
npm ci
npm test
npm run check:csp
npm run check:site
npm run build:edge
npx --yes wrangler@4.152.0 deploy --dry-run --config edge/wrangler.preview.jsonc
npx --yes wrangler@4.152.0 dev --config edge/wrangler.preview.jsonc --local --host preview.workers.dev --port 4181
```

`--host` в локальном режиме позволяет проверить страницу без HTTPS-редиректа
канонического домена. Браузерные проверки используют `SITE_TEST_URL=http://127.0.0.1:4181`.
Проверены Chromium/WebKit, приватность, CSP, формы и документы без JavaScript.

## Публикация из уже авторизованного Cloudflare-окружения

Сначала развернуть preview без маршрутов production:

```sh
npx --yes wrangler@4.152.0 deploy --config edge/wrangler.preview.jsonc
```

Проверить опубликованный preview, тариф/квоты Workers и сертификаты домена.
Затем из того же подготовленного коммита:

```sh
npx --yes wrangler@4.152.0 deploy --config edge/wrangler.jsonc
```

Production-конфигурация задаёт только `metov.store/*` и `www.metov.store/*`.
Другие поддомены, «Завод», connect и магазины не входят в маршруты. Для Worker
Route соответствующие DNS-записи должны быть проксированы Cloudflare; произвольные
изменения DNS этим пакетом не выполняются. Для отката отключить эти два Worker Route:
при сохранённом DNS origin снова отвечает существующий GitHub Pages.

После публикации проверить главную, условия, инструкцию, файлы подтверждения,
301 без цепочки, отсутствующий URL с 404, загрузку JS/CSS и вход по коду.
`run_worker_first` включает Worker для запросов ресурсов: лимит и стоимость
Workers нужно оценивать по фактическому тарифу аккаунта. Бюджет аккаунта в этой
среде недоступен; бесплатная или неограниченная эксплуатация не заявляется.
